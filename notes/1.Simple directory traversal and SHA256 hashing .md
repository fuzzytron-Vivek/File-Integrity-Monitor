# FIM v1: C++ Notes

## Arrays and Pointers

```cpp
unsigned char md[32];                          // array, not a pointer
std::string byte_to_hex_lookup(const unsigned char* bytes);
byte_to_hex_lookup(md);                        // md decays to &md[0]
```

| Concept | Meaning |
|---|---|
| Array decay | In most expressions, `md` becomes `&md[0]` |
| Parameter `bytes` | Pointer to `md[0]`; **no copy** of the 32 bytes |
| `bytes[i]` | Same as `*(bytes + i)` |
| `const unsigned char*` | Read-only access to the bytes (digest is only read) |

---

## Bytes to Hex

> [!NOTE]
> 1 byte = 2 hex chars, so SHA-256 gives 32 bytes → **64 hex chars**.

One byte splits into two **nibbles** (4 bits each):

```text
1010 0111  →  A7
upper lower
```

| Nibble | Expression | Example | Result |
|---|---|---|---|
| Upper | `bytes[i] >> 4` | `1010 0111 >> 4` | `0000 1010` = 10 |
| Lower | `bytes[i] & 0x0F` | `1010 0111 & 0000 1111` | `0000 0111` = 7 |

> [!TIP]
> `0x0F` = `0000 1111`, a mask that keeps the lowest 4 bits.
> General rule: to keep the lowest *N* bits, use a mask of *N* ones.

---

## Lookup Table

```cpp
static const char hex_chars[] = "0123456789ABCDEF";
```

A nibble (0-15) is used directly as an index: `hex_chars[10]` → `'A'`, `hex_chars[7]` → `'7'`.

---

## Output Indexing

Each input byte writes two output chars:

```cpp
result[i * 2]     = hex_chars[bytes[i] >> 4];
result[i * 2 + 1] = hex_chars[bytes[i] & 0x0F];
```

| Byte | Output slots |
|---|---|
| 0 | `result[0]`, `result[1]` |
| 1 | `result[2]`, `result[3]` |
| 2 | `result[4]`, `result[5]` |

---

## Full Flow

```text
byte → split nibbles → lookup in hex_chars → 2 chars
32 bytes → 64-char std::string
```
